# FitTracker AI

A personal fitness platform that helps users track weight, calories, body measurements, and progress toward health goals.

## Features

- Weight tracking
- Calorie calculator
- Daily calorie logging
- Progress charts
- Goal management
- Body measurements
- AI-powered recommendations

## Version 1 Goals

- User profile
- Weight tracking
- Calorie calculator
- Progress dashboard

## Future Features

- Food recognition with AI
- Smartwatch integration
- Personalized nutrition plans
- AI fitness assistant

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
